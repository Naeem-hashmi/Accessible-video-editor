# Accessible Video Editor

A video editor for Windows built first for screen reader users. It works with **NVDA**, **JAWS** and **Narrator**, and everything is done from the keyboard.

It can trim and split clips, join several videos, add music, voice and sound effects, layer pictures and videos over each other (logos, picture in picture), add picture and sound transitions, clean up sound (noise reduction, hum removal, equaliser, voice presets), and export high-quality video for YouTube and social media.

## How it works

- **Layers and items.** A project is a stack of layers. Layer 1 is at the bottom; higher video layers appear in front. Each layer holds items that play one after another.
- **A keyboard grid.** `Left` and `Right` move between items in time. `Up` and `Down` move between layers at the same time, so any number of layers is easy to reach. `Alt+1` to `Alt+9` jump to a layer and listen to it alone; `Alt+0` listens to all layers.
- **J, K, L.** `J` jumps back, `K` or `Space` plays and pauses, `L` plays faster. `M` mutes the focused layer and `Shift+M` solos it.
- **Markers.** `[` and `]` set range start and end, `B` adds a marker, `Alt+Left` and `Alt+Right` jump between markers.
- **Arranging.** `Alt+J` and `Alt+L` slide an item in time; `Alt+Shift+Left` and `Alt+Shift+Right` change its order.
- **Speech that never fights the screen reader.** Messages go to NVDA or JAWS directly when they are running, otherwise through Windows UI Automation. When focus moves, the message is read as part of the newly focused item, so the two never cut each other off.
- **Standard Windows controls only.** Menus, lists, tabs, text boxes and combo boxes, with every field labelled. Nothing is a custom drawing that screen readers can't read.
- **Copyright-free sounds.** The built-in earcon themes and the library of 18 sound effects and music beds are generated by the program's own synthesizer, so they are free to use in any video.

Read the [user guide](docs/USER_GUIDE.html) and the [keyboard reference](docs/KEYBOARD.md).

## Download

Each push builds a Windows installer and a portable zip. Find them under **Actions**, open the latest successful "Build and test" run, and download the **AccessibleVideoEditor-windows** artifact. The installer bundles everything it needs, including FFmpeg; nothing else has to be installed. It needs 64-bit Windows 10 (version 1809 or later) or Windows 11.

## Project layout

| Folder | What it holds |
|---|---|
| `src/AccessibleVideoEditor.Core` | Everything that is not a window: the project model, timeline maths, edits and undo, the keyboard command table, spoken descriptions, the FFmpeg render engine, sound synthesis, templates and checks. Cross-platform and fully unit-tested. |
| `src/AccessibleVideoEditor.App` | The Windows app (WPF): window, dialogs, speech output, earcons, preview player and a built-in self-test. |
| `tests/AccessibleVideoEditor.Core.Tests` | Unit tests and integration tests that render real media with FFmpeg and check length, pixel colours and loudness. |
| `tools/AccessibleVideoEditor.AssetGenerator` | Writes the built-in sounds for the installer and generates the keyboard reference. |
| `installer` | Inno Setup script. |
| `docs` | User guide, keyboard reference, architecture, testing plan and the original research. |

## Building

You need the .NET 8 SDK and FFmpeg (on Windows, put `ffmpeg.exe` and `ffprobe.exe` in `ffmpeg` next to the program, or set `FFMPEG_PATH`).

```
dotnet test tests/AccessibleVideoEditor.Core.Tests
dotnet publish src/AccessibleVideoEditor.App -c Release -o build/app
dotnet run --project tools/AccessibleVideoEditor.AssetGenerator -- build/app
```

The core library and its tests also run on Linux and macOS. The app builds on any platform but runs only on Windows. Continuous integration (`.github/workflows/build.yml`) runs the tests on Linux and Windows, runs the app's self-test on a real Windows desktop, and builds the installer.

After changing commands or keys, regenerate the keyboard reference:

```
dotnet run --project tools/AccessibleVideoEditor.AssetGenerator -- --docs docs
```
