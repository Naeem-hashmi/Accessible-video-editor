# Accessible Video Editor

A screen-reader-first video editor for Windows, designed for NVDA and JAWS users.

Goal: let blind and low-vision creators trim video, add audio, combine multiple
videos and layer images and video, entirely from the keyboard, with a minimal,
Windows-native interface.

## Status

Research and design phase. Start with [docs/RESEARCH.md](docs/RESEARCH.md), which covers:

- what existing open-source editors and engines offer, and how accessible they are
- the recommended stack (C#/WPF, libmpv for preview, FFmpeg for export)
- the accessible UX design, keyboard map, architecture and roadmap
